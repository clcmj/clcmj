## 正在开发

### 帧刻 · 屏幕动图录制工具

在 Mac 上框选屏幕区域，录制一段操作，预览并裁剪片段，再导出循环动图。适合给教程配图或记录软件操作。

> 框选区域 → 录制操作 → 裁剪片段 → 导出动图
